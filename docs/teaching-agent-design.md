## 内容与来源

课程目录统一提供 14 页新手教学和 15 课/58 步进阶练习。新手保留原弹窗 UI，补充打吃后逃跑、连接与断点、整块提子，使用集中在 `beginnerTutorial.ts` 的内容与稳定 ID；首次入口、设置重看和目录选页共用。基础落子和棋盘识别不另增重复页。新手为引导体验，不计入进阶通过率或独立掌握证据。

进阶从真假眼、做活继续到攻防、收官与综合练习，不重复新手已覆盖的基础主题；劫课仅将第一页归入新手，后四页保留为“劫的应用”。原始 OGS 25 课/98 页和 Go Game Guru 4 课/16 题仍完整保留在 `sourceCurriculum.ts`（29 课/114 步），未改源题 ID、版本与答案树。`curriculum.ts` 根据新手内容中的主题映射筛选目录并重建有效先修关系；既有学习记录不被删除。

## 教学交互

1. 从原题完整局面开始，由人物给出任务，直接操作棋盘。点已有棋子查看整块棋的子数与气；气线按实际相邻关系绘制，悬停不自动泄露数气答案。OGS/GGG 字母和图形标记随局面显示。
2. 合法作答沿原题分支执行对方应手。界面先显示学生一手，再约 420 ms 后显示应手；预览期间暂停棋盘输入。定时器只管展示，不写棋局，换题、退出和卸载会清理。
3. 原题明确正确节点才记录成功，节点即使有后续解释分支也可完成；未知叶或未收录的合法落子不被强行判错/判对。落子题失败或离开可验证变化时立即进入反馈，提示重试或悔棋，不再自动进入自由试下或补启蒙 AI 应手。原题明确反驳仍展示其应手；重试恢复完整起始局面，撤回恢复上一处选择。
4. 提示先给观察方向，再指向当前分支的一种可行下一手；不会在第二手继续圈开头坐标。原题说明、查看气、提示与示范记录辅助曝光。
5. 示范始终从当前题的完整起始局面生成，每次只走一手，可前后查看，也可随时返回原来的答案、选择或反馈局面。正确节点后的原题解释性续着保留，遇到无法确定的分叉停止，不猜答案。不会切换成另一张课级示例棋盘。
6. 选择题失败后可原地改选；停一手、选择死子、结束对局使用各自操作。选死子时点击整块切换选择，确认前不删除棋子；按原题目标核对后更新整份局面。
7. 课程按顺序继续未完成步骤，不因看过提示或暂时离开就跳过基础页。选课、复习、收藏与学习记录放在课程弹层，完成后可主动进入新的一盘 9 路陪练。

共用现有 GameBoard、CoachPet、CoachBubble、Panel、TopBar 和 Button，维持木色、圆角、简洁可爱的视觉。窄屏允许纵向滚动，人物气泡不固定覆盖棋盘。新手短引导与陪练入口保持各自职责。

## 状态、规则与学习记录

`AppController → useTeachingWorkspace → useLearningCenter / useLearningPractice / useLearningProgress`。center 管目录、开关、owner/generation、备份与统计；practice 管独立练习、应手、示范、撤回和完整 `GamePosition` 快照。课程与个人复盘题共用 `gradeExercise / applyExerciseGrade`，源树及终局动作由 `sourceExercise.ts` 处理，示范/提示及非法落子反馈经 `exerciseInteraction.ts` 复用现有规则和 `positionState`。

教学不向正式对局写棋子。进入教学同步取消陪练请求和延迟 AI 落子，并暂停对局调度、自动模型初始化与复盘分析；换账号、换题、退出、重置和卸载使旧回调失效。异步备份读取绑定独立 generation。

OGS 劫题第 5 页明确给出上一手白棋提子；适配时用实际规则验证并还原这一手的完整历史、提子数与落点，使立即回提按劫规则拒绝。其他没有历史证据的摆棋题不推测先前着手。

学习记录沿用 IndexedDB owner 分区、完整作答/曝光记录、收藏和校验后的备份合并。首次答案先记录再反馈；重试保留 `retryOf`，不会覆盖失败或把已看过答案当作独立掌握。同一原题共用题族，翻译/布局更新不虚增独立证据。完成按每题成功及内容版本计算；到期复习与独立证据分开。

## 验收边界

全量工程入口为 `npm run check`（contracts → lint → typecheck → test → build）及 `git diff --check`；来源导入一致性、原分支合法性、实际 grader、hook 生命周期和 UI 交互分别验证。真实浏览器覆盖桌面、手机与矮横屏，结果详见验收记录。

工程验收和成熟来源不能代替专业中文审校、真人试学与隔天迁移评估。本版本不承诺从零达到特定段级；完整布局/官子体系、整盘引导实战和更复杂死活仍不完整。自由试下 AI 不作为题解权威。真实 ONNX 推理、Android 与 TapTap 原生验收不由本轮 Node 回归替代。
