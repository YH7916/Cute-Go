# 陪练端云协同验收（2026-10-04）

本轮范围：陪练尊重当前对局设置；共享本地 ONNX 的对手落子与玩家分析；压缩云端讲解上下文；限制长局历史和缓存。没有提交、推送或部署。

## 执行与证据

- 一个 AI Worker / 一份模型。对手走所选难度，陪练使用独立浅搜预算：默认 8 次访问，每个指定点加 8，最多 32；正常应手优先，取消及完整局面校验隔离过期结果。
- 候选携带 prior、真实访问的黑方价值估计、最多四手合法示例变化。指定点保留但按访问数排序；本地推荐另行选择最高访问候选，避免把被询问的弱点当作推荐。
- 云端收到实际棋盘尺寸、难度、执子、贴目、完整压缩棋盘、相关规则事实及本地引擎证据。证据 JSON 上限 6000 字符，默认不传问答历史，具体问题最多三轮；不是 token 精确计数。
- 默认回复 80 字、具体问题 160 字，最多两句；单次 API 输出上限 384 tokens。DeepSeek 官方端点发送关闭 thinking 参数，其余兼容端点不发送该专有字段。
- 本地问答保留六轮，回答及分析缓存各最多八项。临时缺少 ONNX 结果的回答不缓存；具体问题的缓存还绑定最近三轮上下文，避免相同追问引用旧主题。

## 已执行验证

- 全量入口：`npm run check`（contracts → lint → typecheck → test → build）通过，1241/1241 项测试成功；结果见 `output/coach-edge-cloud-check.log`。`git diff --check` 通过。
- 真实生产浏览器：5/9/10/13/19 路 × 简单/中等/困难，分析、取消恢复和双角色串联共 24 项通过。排序修复后另复跑 9/13/19 路真实对手落子及另一执子分析，共 6 项通过；始终只有一个 Worker，结束释放。
- 最终 ONNX / WASM、两个指定点、24 次访问的单样本耗时：9 路 1.57 秒、13 路 3.08 秒、19 路 5.56 秒。实测为本机开局局面，不能外推手机或长局最坏耗时。
- 浏览器设置实际切到 13 路、困难、执白；返回首页再进入陪练保留配置，对手先行。真实 ONNX 经教学 Worker 发到本机模拟 HTTP 服务，收到短文本并在棋盘标点。该请求证据 2608 字符，含白方行棋、7.5 贴目、候选真实 prior/Q/变化。模拟服务只验证传输与渲染，没有调用真实大模型。
- 300 次真实 hook / runtime 问答回归验证历史上限、上下文限制、跨局隔离。19 路生产规则生成合法 100/300 手局面，默认云证据为 2687/3198 字符，带历史为 4039/4371 字符。
- 独立 Node 基线（预热四次后取 20 次中位数）：100/300 手的规则证据构建 1.05/3.36 ms，教学 inspect 0.71/2.51 ms，上下文构建 0.29/0.31 ms，完整输入 structuredClone 1.26/6.21 ms。重复运行会随机器负载浮动，不作为固定通过阈值。
- 最终全量测试并发运行时，300 手 structuredClone 中位数 11.99 ms、单样本峰值 107.12 ms；该 Node 负载场景不是浏览器卡顿实测，但说明完整历史复制仍有后续优化空间，不能宣称长局端侧处理恒定耗时。
