# 陪练操作收为常驻一行

## 改动

- 原“讲解上一手”和“分析形势”合并为“讲解当前局面”，复用 `explain-position`。危险弱棋优先，其次已验证的提子、解围、连接、停着，普通局面再讲开局与围空；对手被打吃时检查合法提子，不能引导玩家救对手或承诺必吃。
- 操作栏只留讲解、提示、有棋谱时的回看。删除更多、重复设置、收起和全部折叠状态；继续使用原 Button、Panel、主题和人物布局。
- 设置继续走顶部；最近问答进入现有复盘工具。云配置默认空，已配置用户的提问框直接可用，草稿保留。
- 本轮没有改变上一轮已修的阅读连续性、关键变化常开和局面归属边界。
