# 陪练手机交互调整

需求：陪练沿用普通对局布局；讲解框复用既有主题并缩小；使用卡通褚嬴作为有配套动作的游戏内助手。

## 实现

- `AppView` 移除陪练专用 `contents`、上下排序和棋盘比例分支，共用普通对局的容器与位置。
- `CoachPanel` 复用 `Panel`、`Button`；标题、短讲解、两个常用动作。未配置时隐藏不可用输入框；已配置时显示提问与发送；自动讲解放入“更多”。所有按钮至少 44px 高，输入文字 16px。
- `CoachAssistant` 默认收起；手机展开为底部紧凑浮层，桌面在助手旁展开。点击棋盘或其他区域收起，Escape/关闭按钮返回助手焦点。
- `CoachPet` 只播放生成的精灵图；状态映射为待机、请求中思考、面板展开讲解、结束鼓励。减少动态效果偏好时静止显示，页面隐藏时暂停动画。
- 空盘引导改为简短欢迎语。
- 服务配置改为设置中的二级页面，沿用原有弹窗、Panel、Button；服务商使用项目已有图标库，提供返回与关闭。服务保存不调用对局重开。
- 褚嬴画布从 80px 放大到 96px；手机保持原有计分行高度，衣摆落在按钮上方留白中，横屏位于右下角。

## 真实 DeepSeek 空回复诊断

- 初次成功不代表稳定：再次调用出现空正文。玩家确认要求教学 Agent 的讲解与提示均关闭 thinking，直接输出简洁正文。
- IAB CDP 只读响应摘要：HTTP 200、`finish_reason=length`、正文长度 0、思考字段长度 880、completion_tokens 513。仅记录长度和状态，不保存思考内容或请求密钥。
- 根因：512 token 输出上限被默认思考过程耗尽；客户端先判断空正文，错误提示“不支持 Chat Completions”，掩盖了截断原因。
- 参考 [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/) 的 `thinking.type=disabled`，以及 [OpenCode 模型配置](https://opencode.ai/docs/models/) 按供应商/模型配置选项的方式。只对官方 DeepSeek 接口附加该参数，不向其他兼容服务盲发私有字段。
- 定位：围棋教学 Agent；本地规则生成可信棋局事实，云端用 1–3 句解释或提示，棋盘继续作为主要交互区域。
- 修复后门禁 454/454 通过；真实 DeepSeek 的“讲解”“提示”均 HTTP 200、finish_reason=stop、reasoning_content 长度 0，分别返回 2 句和 3 句正文。当前两手棋 C7 黑棋、D9 白棋，讲解正确指出白棋在上边线左侧、3 口气、没有提子。未改动玩家保存的地址、模型或密钥。
