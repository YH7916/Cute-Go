# Pi 云端讲解迁移验收

日期：2026-10-24。环境：Windows、Node.js 24.14.0；依赖锁定官方 Pi Agent Core / Pi AI 1.4.0。

## 本次行为

- 前端只向独立后台发送 `{evidence, question}`，不再选择供应商或发送模型 API 密钥；旧 v1 设置清除，新的访问令牌使用 v2 设置。
- Node 后台运行真实 Pi Agent 和三个只读围棋工具，每次请求独立上下文；保留端侧局面归属、规则/ONNX 证据、输出验证、本地回退。
- 前后端分别产出 `dist/` / `dist-server/`，后台来源白名单、访问令牌、并发、超时及取消生效。

## 实际验证

- `npm run check`：退出码 0；contracts → lint → typecheck → test → build 全通过，**1331/1331** 测试通过，0 失败/跳过。日志：`output/pi-coach-check.log`。
- `git diff --check`：退出码 0。
- 真实端侧 runtime → 真实 HTTP 后台 → 真实 Pi SDK → 本机 SSE 模型 fixture → 前端响应校验：有效讲解成功、非法引用/坐标回退且不缓存、取消关闭上游连接、后续请求恢复；令牌与棋局隔离。
- Pi 工具与模型调用预算、超时、请求快照隔离、主动静默、推理内容隔离、供应商专属参数和错误脱敏均有运行回归。
- HTTP 来源绕过负向回归先复现伪造 Host + Origin 被接受，再修复为仅接受显式配置的浏览器来源；HTTP 与 Pi 组合回归通过。
- 后台生产产物曾以合成环境配置启动：预检 204、无效证据 400、缺令牌 401，未调用外部模型。
- Playwright 隔离会话实际查看桌面 1440×900 与手机 390×844 设置界面；输入框和按钮完整，无水平溢出。截图：`output/playwright/pi-coach-desktop.png`、`output/playwright/pi-coach-mobile.png`。
- 浏览器实测合成地址/令牌保存、关闭重开保留；修改地址立即清令牌和记住状态；清空地址后本地提示仍可用。此浏览器检查未连接后台或替换网络路由，完整 Pi 调用证据来自上述 HTTP 组合回归。隔离浏览器与本次启动的 Vite 已关闭。
- 前端生成的 JS 未检出 Pi 包标识、后台 runtime 符号或后台提示词标识；架构负向测试阻止前端导入后台与 Pi 包。
