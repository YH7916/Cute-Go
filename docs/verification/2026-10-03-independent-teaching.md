# 独立教学模式验收

> 历史快照：本轮之后已按用户反馈恢复原新手教学，后续课程改为直接落子、按需示范；当前课程与入口见 [直接练习与新手收尾验收](2026-10-03-practice-first-teaching.md)。本文保留当时的测试和截图证据。

日期：2026-10-03。范围：教学与陪练分离、基础课程重整、原伴学 UI 复用。保留工作区已有修改；未提交、推送或发布，默认云服务仍未配置。本文替代当天较早的 [教学闭环验收](2026-10-03-teaching-loop.md) 中的课程与界面现状。

## 本轮结果

- 首页“围棋教学”和“陪我下棋”为独立入口；教学使用自己的完整局面，进入时取消正在等待的对局 AI / 陪练任务，退出、换题、换账号和导入后的旧回调失效。
- 13 节基础课、26 道练习：18 道一步落子、4 道连续变化、4 道数气/数地。先棋盘示范，再自己作答，再观察结果。正式课程撤下文字选择题。
- 连续变化首手后执行对方应手，完成整段目标才记成功；退一步同时撤回相应应手。错误反馈描述实际局面，有核验过的反驳则展示反驳，未知合法分支不冒充坏棋。
- 复用 GameBoard、CoachPet、CoachBubble、TopBar、Panel、Button 与原主题；主屏只有一张棋盘，目录、来源、复习与备份按需展开。
- 沿用本机学习记录；旧局面保留原题族，示范、重试和旋转变化不刷独立证据，旧版本文字题的成绩不自动算作新棋盘课程通过。

教学组织及内容限制见 [设计](../teaching-agent-design.md)，教程和竞品核验见 [来源笔记](../teacher-source-notes.md)。

## 工程验证

`npm run check` 全部通过：contracts → lint → typecheck → test → build；**847 项测试通过，0 失败、0 跳过**。`git diff --check` 通过。完整输出：[检查日志](../../output/independent-teaching-check.log)。

关键回归覆盖：

- 每课示范通过真实规则重放，占位/自杀/劫示范返回预期原因；每个初始棋块有气，每道题存在合法目标答案。
- 连续题中间步骤不记成功、白方视角、提子目标不足、题后额外落子、具体错误反驳；两眼与切断的反例。
- 正式局面保持原样，教学进入前请求取消、延迟 AI 回包不落子、旧正式棋盘输入被阻止；新谱导入退出教学。
- 退出或切换账号后的旧按钮不能重新打开教学；迟到备份读取不能恢复旧会话；课程不被个人收藏题替代。
- 错误提子反馈不得宣称目标已离盘；非法落子说明具体规则原因，成功才给成功讲解。
- 教学优先渲染且不叠加首页/对局界面；陪练保留原计分卡与操作。

首次全量检查发现一个 AppView 测试 fixture 缺少教学状态；补齐 fixture，保留原断言后重跑通过。构建仍报告既有 Browserslist 数据过期和 ONNX 依赖内 eval 提示；未升级依赖或放宽检查规则。

## 真实浏览器验收

本机 Edge / Playwright 隔离会话，Vite `http://localhost:5182`。使用真实页面点击、落子与输入；桌面 1280×800、手机 390×844、矮横屏 844×390，截图已实际查看。

| 流程 | 观察结果 |
| --- | --- |
| 首页进入教学 | 单棋盘与原角色气泡，课程目录按需打开 |
| 首课示范 → 自己落子 | 占位示范保留棋盘和轮次；合法白棋示范后进入学生练习，落子直接反馈 |
| 数气 → 错答 → 重试 → 答对 | 数值输入与结果可见，按钮可操作，重试恢复初始局面 |
| 数地 | 展示已确认活棋、无死子的条件；输入标签为“目数”，输入 2 后通过 |
| 倒扑 | 第一手后白棋自动提子，仍在“试一试”；退一步恢复，重走两手后提 3 子才通过 |
| 提子错落到远处 | 白子仍在盘上，反馈实际提 0 子及观察方向，不再附上成功提子说明 |
| 教学返回首页 → 陪我下棋 | 回到原 9 路对局 UI，计分、悔棋、停着、重开和角色气泡保留 |
| 矮横屏 | 单棋盘，无页面横向溢出，主要操作按钮位于视口内 |

## 限制

- 内容仍是参考教师教案整理的 original-draft，经规则检查但未经专业教师审校；没有取得或搬运完整商业教材题库。
- 当前覆盖基础提逃、规则、两眼与简单数地，尚非从零到初段的完整课程。多分支复杂死活、布局、中盘和官子需要后续逐题审校；有限变化不证明任意应手下的强制结果。
- 未做真实初学者学习效果、隔天陌生棋形迁移评估。
- 浏览器尺寸模拟不等于手机真机；本轮未重新验收真实 ONNX 推理、Android、TapTap 原生或云端付费模型。
