# 围棋教学基础闭环验收

> 历史记录：本文对应当天较早的实现；课程数量、教学入口与界面已由后续改动替代。当前结果见 [独立教学模式验收](2026-10-03-independent-teaching.md)，本文保留当时的验证证据。

日期：2026-10-03。范围：当前工作区的教学增量；保留既有改动，未提交、推送或发布。默认云服务按要求未配置。

## 交付内容

- 讲解：一次供应商请求，有限事实和概念选项，本地校验与渲染；无效输出退回本地。最近六轮问答绑定原局面，终局允许手动提问，自动保持安静。
- 复盘：中盘/导入棋谱可直接“回看棋谱”；规则事件、独立试下、悔棋、停着、回原谱、收藏。进入复盘同步取消对弈 AI，迟到 move/pass 和延迟落子不能改原谱。退出不伪造终局；切账号立即废弃旧收藏分支。
- 练习：课程、错题、复习、个人棋局共用判题和会话。48 个目标、96 道原创题，其中 7 道棋盘规则题、89 道条件理解选择题。默认先作答，讲解和提示按需显示并记录曝光。
- 学习记录：按本机 owner 分区的 IndexedDB；作答、提示、收藏、备份合并/删除。新题独立证据与旧题间隔复习分开；读取失败保留原记录，暂停覆盖，内存数据仍可导出。

架构及限制见 [当前方案](../teaching-agent-design.md) 和 [真实调用链](../architecture.md)。统一判题入口已登记到架构契约，并由独立缺失导出反例校验。

## 工程验证

`npm run check` 全部通过：contracts → lint → typecheck → test → build；**825 项测试通过，0 失败/跳过**。`git diff --check` 通过。完整输出：`output/teaching-completion-check.log`。

关键回归覆盖：

- 编造事实、未知引用、任意自由正文、课程答案泄露、六轮历史脱敏；19 路多棋块请求预算。
- 原谱与结算棋盘隔离、试下规则与连续停着、重开/切账号/切手/进入复盘后的迟到结果。
- 数气、提子、连接和解围的真实规则判题；普通压气不得叫打吃，个人题复用课程技能 ID。
- 本次提示与题后反馈的区分、独立标签稳定、隔天复习、坏存档保护、持久化失败、所有者隔离、迟到导入取消。
- 课程清单与先修无环、答案提交前不展示、旧练习回调不改新题、原棋局保持不变。

构建仍有既有 Browserslist 数据过期和 ONNX 依赖内 eval 提示；本轮未升级依赖或降低规则。

## 浏览器实测

使用隔离 Playwright 会话与本机 Edge，Vite `127.0.0.1:5179`。查看 1030×610 / 1280×800 桌面和 390×844 手机宽度；没有填写供应商密钥或调用付费讲解。

1. 从首页打开围棋学堂，数气题先独立提交 6，再在不同情境看提示提交 3。两次判分正确，IndexedDB 实际保存 `hintLevel=0 / 1` 与对应曝光。
2. 刷新页面后再次打开学堂，显示 1 项已练、1 项有独立答对、0 项隔天新题答对；没有把辅助答对重复计为独立证据。
3. 导入 `(;GM[1]FF[4]SZ[9];B[ab];W[bb];B[ba];W[hh];B[cb];W[hi])`，由“回看棋谱”进入第 6 手。收藏局面后试下 B[bc]，显示试下 1 手、黑提子 1；返回原谱后仍为 6 手、黑提子 0。
4. 在“我的棋局”打开该提子练习，实际点击 B[bc] 并提交，反馈本手提掉 1 子；记作巩固练习。关闭学堂后原谱仍为 6 手、黑提子 0。
5. 复盘手动本地讲解返回当前白棋块 5 气的说明，并加入最近问答；点击“查看当时局面”进入独立分支。退出后悔棋/停着仍可用，未错误弹出终局窗口。
6. 手机复盘最初把棋盘挤得过小，已修为可滚动布局并保留至少 320px 棋盘行；复查桌面与手机截图。

## 未覆盖项

- 96 道题为原创草稿，尚未获得专业围棋审校；89 道条件理解题不等于 89 道棋形读棋题。没有宣称段级、完整死活训练或真实学习效果已验证。
- 结构化选择保证文字来自给定素材，不保证模型一定选中最切题的素材；本轮未用真实供应商重新评测讲解质量。
- 未新增官方深 KataGo、默认托管 API、多设备同步、多人多标签并发学习合并。
- 浏览器宽度检查不是 Android 触控、TapTap 原生或性能验收；本轮未重跑完整 ONNX 推理验收。既有专用验收入口继续保留。
