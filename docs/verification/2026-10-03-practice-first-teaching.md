# 直接练习与新手收尾验收

日期：2026-10-03。范围：纠正新增教学的起点与节奏，保留原新手教程，并简化新手结尾。默认云服务仍未配置；未提交、推送或发布。本文替代同日较早验收中“基础课重复教学、每课先示范、移除原新手教程”的现状描述。

## 实现结果

- 新手规则仍由原 TutorialModal / TutorialStates 承担：首次访问沿用 seen 标志自动打开，围棋设置可重看，首页不设新手入口。末尾保留一句棋盘操作提示，将陪练说明和难度长页合并为一页“接下来，随你探索”，总计 11 页。
- 探索页提供进阶教学、本地双人、联机对战、AI 对战、AI 陪练五个入口；先关闭教程并记录 seen，再调用现有启动函数。联机只打开既有面板，不自动建房或匹配。
- 进阶课默认直接落子，选课和下一课都不强制看示范；错误后主操作为重试。提示、示范按需打开，示范结束回原题；先前作答不被覆盖，辅助与独立记录分开。
- 六课十二题：救棋选择、切断接应与追吃方向、双打吃兑现、连续追吃、倒扑、保眼补墙。四题一步决策、八题连续变化，撤下重复规则题；基础概念仅保留文字供陪练引用。
- 第一课直逃会遭反驳，反提能解围；第二题增加援兵，直逃连回与反提都合法正确。连续追吃包含四手/六手的学生落子，等真正完成提子才通过。
- 棋盘、角色、气泡与原按钮复用。新手禁入点和两眼摆图的两处旧错误已修正，并以真实规则回归验证。

当前路线及限度见 [教学设计](../teaching-agent-design.md)，来源见 [资料笔记](../teacher-source-notes.md)。

## 工程验证

`npm run check` 全部通过：contracts → lint → typecheck → test → build；**871 项通过，0 失败、0 跳过**。`git diff --check` 通过。输出：[全量检查日志](../../output/practice-first-teaching-check.log)。

回归覆盖：

- 进入课程即 practice、选课即 practice、默认无提示曝光；失败主操作立即重试；只有主动选择才看示范。
- 示范结束回同一道题，标记辅助；失败后看示范只影响重试，不改写原首答。换课、关闭、换账号、迟到导入和旧回调隔离继续通过。
- 新手首次访问/已看标志、手动重看、原振动和动画偏好；末页五个入口全部映射到现有模式函数，导航先关闭教程。
- 首课反提与援兵下的两种解法、双打吃后的所有合法白应手仍可提子、连续追吃的多种已收录追法、保眼补墙的真实结果。
- 原通用判题负向用例继续保留为独立棋形：劫、自杀、假眼、白方视角、提子目标不足、额外答案、切断时不能吃掉目标后冒称切断，以及完整局面过期写入保护。
- 新手禁入点对界面当前黑方确实自杀；指定做眼点落下后，两眼由同一黑链围住，白点任意一眼都不合法。

另有独立只读棋形复核：重放所有收录序列与白应手；修正一条眼题反馈后复核一致。此复核是工程规则审查，不是专业教师审校。

构建仍有既有 Browserslist 数据过期和 ONNX 依赖 eval 提示；未升级依赖或放宽规则。

## 浏览器实测

Playwright / 本机 Edge，`http://127.0.0.1:5182/`，使用隔离浏览器会话。桌面、手机 390×844 和矮横屏 844×390 均实际操作并查看截图。

- 原新手教程可重新打开，末页五个入口各有一句用途说明。
- 进入进阶首课直接处于“试一试”，无需点继续演示；主屏一张棋盘。
- 首课向下接长后白自动反驳并提走两颗黑棋；重试立即恢复题目，主动看示范可进入讲解。
- 示范后回到原题，反提成功并保持辅助标记；成功反馈精简为实际气数与反提作用。
- 从新手末页实际点通进阶、本地双人、AI 对战和 AI 陪练；联机入口打开原联机面板，未建房或匹配。五个入口的函数路由均另有自动回归；点击 AI 对战入口不等于完成模型推理质量验收。
- 首次访问自动显示新手教学，关闭后刷新不再弹出。换课直接练习、连续应手和撤回也已操作验证；Console 仅见既有 favicon 404 与 WebGPU fallback，无新增应用异常。
- 横屏探索页复用原按钮改为两列，五个入口全部显示，无需滚动寻找最后一项；竖屏保持单列。最终横屏截图已再次实际查看。
